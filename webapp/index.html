How to get the link

  1. Open the Colab notebook and run the server cell.
  2. Wait until it prints PHONE ME YE LINK KHOLO and a link.
  3. Open that link here (or paste it above). Colab gives a new link every time you restart it.
To install: in Chrome open the menu and choose Add to Home screen or Install app.

Run on this phone

Photos are made on the Colab GPU, so this needs internet and a running Colab. Making photos on the phone itself is only in the Full Android app.

Needs a phone with 8 GB RAM or more. One photo takes from about 15 seconds to a few minutes. On the phone there is no negative prompt and no image safety check, so only the prompt filter applies.
Safe photos only. The server filters prompts and checks every image. This cannot be switched off from the app.
